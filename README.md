# ELEMENTA

Одностраничный сайт вымышленного бренда витаминов. Концепт для портфолио.

**Демо:** https://m-anttt.github.io/vitamins/

## Стек

Чистые HTML / CSS / JS без сборки и зависимостей. Открывается двойным кликом
по `index.html` — ничего устанавливать не нужно.

## Структура

```
index.html              вся разметка страницы
assets/css/style.css    стили (секции пронумерованы комментариями)
assets/js/main.js       интерактив: меню, аккордеон, счётчики, форма
assets/img/             сюда кладутся картинки и видео
```

| | |
|---|---|
| Кремовый фон | `#F7F5EE` |

| Текст | Literata 300 |
| Подписи | JetBrains Mono, CAPS, tracking `0.14em` |

Все цвета и размеры лежат в `:root` в начале `style.css` — правятся в одном месте.
Тёмные секции переопределяют те же переменные через класс `.surface-dark`.

## Как вставить свои картинки

Большинство слотов уже заполнены реальными фото из `assets/img/`. Оставшиеся —
серые заглушки, каждая подписана тем, что в неё должно лечь, и уже имеет нужные
пропорции:

```html
<div class="media" data-slot="продукт 1 — 1:1" style="--ar:1/1"></div>
```

Чтобы поставить файл, положите его в `assets/img/` и вложите тег внутрь:

```html
<div class="media" style="--ar:1/1">
  <img src="assets/img/product-1.jpg" alt="Витамин D3 + K2 в стеклянном флаконе">
</div>
```

Серая подложка и подпись пропадут сами, файл встанет по `object-fit: cover`.
Для видео так же — `<video src="..." autoplay muted loop playsinline></video>`.

Для фото под текстом (обложка, две категории) добавлен класс `.media--dark` —
он приглушает фото фильтром `brightness`, чтобы белый текст поверх оставался
читаемым. Добавляйте его вручную, если кладёте своё фото в такой слот.

Что ещё остаётся заглушкой:

| Слот | Пропорции | Где |
|---|---|---|
| Биотин + селен | 1:1 | категория «Красота и кожа» |
| Баннер «Саше» | 21:9, широкое | full-bleed секция после каталога |
| 2 статьи журнала | 3:2 | «Витамин D зимой», «Как мы проверяем каждую партию» |
| Деталь-врезка | 1:1 | второе фото в блоке «О бренде» |
