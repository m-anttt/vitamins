# ELEMENT

Одностраничный сайт вымышленного бренда витаминов. Концепт для портфолио.

**Демо:** https://m-anttt.github.io/vitamins/

## Стек

Чистые HTML / CSS / JS без сборки и зависимостей. Открывается двойным кликом
по `index.html` — ничего устанавливать не нужно.

## Структура

```
index.html              вся разметка страницы
assets/css/style.css    стили (секции пронумерованы комментариями)
assets/js/main.js       интерактив: меню, аккордеон, счётчики, форма
assets/img/             сюда кладутся картинки и видео
```

| Кремовый фон | `#F7F5EE` |

| Заголовки | Inter Tight 700, CAPS, tracking `-0.022em` |
| Текст | Literata 300 |
| Подписи | JetBrains Mono, CAPS, tracking `0.14em` |

Все цвета и размеры лежат в `:root` в начале `style.css` — правятся в одном месте.
Тёмные секции переопределяют те же переменные через класс `.surface-dark`.

## Как заменить картинки

Все слоты сейчас заполнены реальными фото из `assets/img/`. Чтобы поставить
своё, положите файл в `assets/img/` и замените `src` у нужного `<img>`:

```html
<div class="media" style="--ar:1/1">
  <img src="assets/img/product-1.jpg" alt="Витамин D3 + K2 в стеклянном флаконе">
</div>
```

Файл встаёт по `object-fit: cover`, пропорция задаётся `style="--ar:Ш/В"` на
обёртке `.media`. Для видео так же — `<video src="..." autoplay muted loop playsinline></video>`.

Если убрать `<img>`/`<video>` совсем, `.media` снова покажет серую заглушку —
достаточно вернуть атрибут `data-slot="описание — пропорция"` на обёртке.

Для фото под текстом (обложка героя, две категории, баннер «Саше») добавлен
класс `.media--dark` — он приглушает фото фильтром `brightness`, чтобы белый
текст поверх оставался читаемым. У обложки героя контраст сильнее остальных
(`.hero__media.media--dark`) — самый крупный текст на странице. Добавляйте
`.media--dark` вручную, если кладёте своё фото в такой слот.
